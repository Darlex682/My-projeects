# Simple Vulnerability Scanner

Небольшая утилита на Python для быстрой проверки веб‑сайтов на распространённые проблемы безопасности. Сканер выполняет базовые проверки и помогает выявить простые недочёты конфигурации.

## Возможности
- Проверка использования HTTPS.
- Анализ ключевых security‑заголовков (CSP, HSTS, X-Frame-Options и др.).
- Обнаружение заголовков, раскрывающих информацию о сервере (Server, X-Powered-By).
- Проверка наличия флагов `Secure` и `HttpOnly` у cookie.
- Простое обнаружение вывода списка директорий.

## Требования
- Python 3.8+
- Доступ из среды выполнения к целевому сайту. В изолированных средах сетевой доступ может быть заблокирован.

## Запуск
```bash
python vulnerability_scanner.py https://example.com
```

Укажите адрес сайта целиком. Если протокол не указан, используется HTTP.

## Предупреждение
Инструмент не заменяет полноценный аудит безопасности и не выполняет активные атаки. Используйте его только на ресурсах, которые вам принадлежат или на которые у вас есть разрешение на тестирование.
