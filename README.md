# Локальная панель проектов

Небольшой локальный сайт с масштабируемым интерфейсом к базе данных. Используется Flask + SQLAlchemy: по умолчанию база SQLite, но URI можно заменить на PostgreSQL или другую СУБД без изменения кода.

## Возможности
- 5 страниц: главная, список проектов, карточка, создание проекта, дашборд + JSON API.
- Поиск по названию и владельцу.
- Подсчёт статистики по статусам.
- Простая адаптивная верстка.

## Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   python app.py
   ```
3. Откройте [http://localhost:5000](http://localhost:5000).

Для смены СУБД замените `SQLALCHEMY_DATABASE_URI` в `app.py` (например, на `postgresql://user:pass@host/db`).
